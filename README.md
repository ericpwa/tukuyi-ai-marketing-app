## 🌟 v2.1 旗艦版本核心升級亮點

1. **Phase 01 品牌底蘊與行銷企劃初建**：
   - 雙軌自選：觀摩「土庫驛中秋結案數據案例」或開啟「開放式條件/AI引導選填」自由建構新案。
   - 完整涵蓋：品牌底蘊（願景/使命/工藝）、結案數據與 **P&L 損益分析**（總營收、毛利、淨利結構）。
   - 引導拆解 **STP (市場區隔/目標市場/定位)** 與 **4P (產品/價格/通路/推廣)**。
   - 一鍵交付「產品市場定位分析 (STP + 4P + P&L) 提示詞」，指示 Gen-AI 生成多頁 PPTX 簡報與一頁式 PNG 圖卡。
2. **Phase 02 目標受眾決策分析**：
   - 3大預設受眾（內部主管40%、福委採購40%、異業高層20%）＋ 自訂受眾開放填答。
   - **Persona 角色模型** ＋ **同理心地圖 (Empathy Map：想/看/說/做/痛點)** 深度洞察。
   - **提案說服策略 (金字塔原則) ＋ NSDB 分析 (Need, Solution, Differentiation, Benefit)**。
   - 交付「目標受眾決策分析提示詞」與整合 Phase 01+02 的「終局版行銷企劃案提示詞」。
3. **Phase 03 視覺生圖實驗室 (ChatGPT & Gemini 雙軌通用)**：
   - 參考「InfoVis Master」與「Infographic Wizard」架構，產出通用於 **ChatGPT (DALL-E 3)** 與 **Gemini (Imagen 3)** 之提示詞。
   - 深入引導填寫「產品特定細節」（85%生巧微距顆粒、天然可可脂光澤、Bonbon星空大理石紋）。
   - 獨家提供 **「70% 純淨留白 (Negative Space)」** 選項，生成高奢無文字背景，徹底杜絕繁體中文變形，專供 PPTX/Canva 後製疊加排版！
4. **Phase 04 工作坊｜行銷企劃簡報生成器**：
   - 終極整合 Phase 01 + Phase 02 + Phase 03，支援一鍵引用前序填寫資料。
   - 3秒一鍵導出：**原生 16:9 PPTX 簡報、獨立品牌 HTML 簡報、Markdown 完整企劃書、JSON 結構檔**。
   - 附帶 Google 簡報與 PowerPoint 雙軌操作秘技。
5. **📊 虛擬與實務數據互動分析 (支援 CSV / XLSX 上傳)**：
   - 保留土庫驛 3 年 B2B 虛擬銷售數據包與 CSV 下載。
   - **新增支援學員上傳真實業務數據包（.CSV 或 .XLSX 試算表）**，自動解析營收、銷量、單價與回購率。
   - **一鍵將分析數據同步回填至 Phase 01 結案數據欄位**，真正落實「數據驅動企劃」閉環！
6. **💡 實戰題型提示詞庫**：
   - 關鍵資訊全數採用 **“［    ］”** 符號留空，方便學員複製並直觀填入自訂專案資訊。
